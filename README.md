# Otimização de Armazenamento em Nuvem

Projeto Final de Projeto e Análise de Algoritmos (PAA) 2026.2, UFC, Campus de Russas.

Dado um conjunto de arquivos, cada um com tamanho (MB) e importância (1 a 100), e uma capacidade de armazenamento, o programa escolhe quais arquivos manter na nuvem para maximizar a importância total sem ultrapassar a capacidade. O problema é modelado como o Problema da Mochila 0/1.
